Thank you to everyone who has contributed to making **Pulse Music** a reality!

## How to Become a Contributor
We welcome contributions from everyone! You can contribute by:
- Submitting bug reports and feature requests.
- Submitting pull requests with code enhancements, bug fixes, and tests.
- Improving documentation and translation strings.
- Testing on diverse Android devices and screen sizes.

Check out [CONTRIBUTING.md](CONTRIBUTING.md) to get started!
